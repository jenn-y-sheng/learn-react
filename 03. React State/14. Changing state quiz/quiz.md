1. You have 2 options for what you can pass in to a
   state setter function (e.g. `setCount`). What are they?
The new version of state to replace the old or a callback function that returns the new value of state, takes the old value as a parameter


2. When would you want to pass the first option (from answer
   above) to the state setter function?
When you don't need to know the old state value to determine the new one


3. When would you want to pass the second option (from answer
   above) to the state setter function?
When you need to know the old state value to determine the new one
